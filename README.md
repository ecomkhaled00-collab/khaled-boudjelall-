## 🚀 نبذة عني

* 🎓 **الدراسة:** طالب علوم اقتصادية وتجارية وعلوم التسيير (جامعة سطيف 1).
* 🏆 **الخلفية:** بكالوريا علوم تجريبية (2024) بمعدل 14.35.
* 💡 **الرؤية:** رفع كفاءة التوزيع، تسريع دوران رأس المال، وفتح أسواق جديدة بضغطة زر.
